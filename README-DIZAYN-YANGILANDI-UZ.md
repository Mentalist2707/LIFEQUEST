# LIFEQUEST — dizayn yangilanishi

Ushbu versiyada funksiyalar o'zgarmagan, ammo interfeys sezilarli darajada yangilangan.

## Nimalar yangilandi?

- Premium dark-fantasy ko'rinish kuchaytirildi.
- Kartalar ko'proq chuqurlik va aniq kontrast oldi.
- Sidebar va bottom navigation yanada zamonaviy qilindi.
- Hero blok, statistika kartalari va progress ko'rsatkichlari jozibaliroq qilindi.
- Login / register ekrani mahsulot darajasiga yaqinlashtirildi.
- Namoz bo'limidagi vaqt kartalari va harakat tugmalari kuchliroq vizual holatlarga ega bo'ldi.
- Mobil ekranda bo'shliqlar, radiuslar va touch ko'rinishi yaxshilandi.
- Umumiy tipografiya, rang muvozanati va hover/focus holatlari yaxshilandi.

## O'zgargan asosiy fayl

- `app/globals.css`

- 18 ta test muvaffaqiyatli o'tdi.
