# LIFEQUEST — namoz tugmasi va ochroq premium ranglar

## Nima o'zgardi?

- Barcha kutilayotgan namozlarda `O‘qidim (+XP)` tugmasi ko'rinadi.
- Namozning haqiqiy vaqti kirganda tugma bosiladi; hali vaqti kirmagan yoki jadvali yuklanmagan holatda tugma **ko'rinadi, lekin vaqtincha faol bo'lmaydi**.
- Vaqti tugagan namozda `Qazo (−XP)` tugmasi paydo bo'ladi. Qazo qayd etilsa `Qazosini o‘qidim` ishlaydi.
- `O‘qidim` tugmasi o'qib bo'lingandan so'ng `O‘qildi` holatiga o'tadi.
- Xato yuborishning oldini olish uchun har bir namozning holati yonida izoh bor.
- Ranglar bir pog'ona ochartirildi: deep navy o'rniga slate/navy, kartalar kontrasti oshirildi, premium ko'rinish saqlandi.
